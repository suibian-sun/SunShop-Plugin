# 易支付插件 - SunShop

## 简介
易支付插件为 SunShop 发卡网系统提供易支付聚合支付接口支持。通过本插件，商户可以接入易支付平台，让用户使用支付宝、微信支付、QQ钱包等多种方式完成支付。

## 功能特性
- 支持支付宝、微信支付、QQ钱包等多种支付方式
- 自动处理支付回调，实时更新订单状态
- 支持订单退款操作
- 支付结果同步跳转
- 详细的支付日志记录

## 安装要求
- SunShop 系统版本 >= 1.0.0
- 有效的易支付商户账号

## 配置说明
1. 在商户后台「插件市场」安装本插件
2. 进入插件配置页面，填写以下信息：
   - **易支付接口地址**：您的易支付平台地址
   - **商户ID**：易支付平台分配的商户ID
   - **商户密钥**：易支付平台分配的商户密钥
   - **默认支付方式**：选择用户在支付页面可用的支付方式

## 获取易支付账号
1. 注册易支付平台账号
2. 创建应用获取商户ID和密钥
3. 配置回调地址为您的 SunShop 系统地址
